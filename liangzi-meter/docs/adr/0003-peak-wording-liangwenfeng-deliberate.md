# ADR-0003：峰谷文案用字「梁文峰/梁文谷」——刻意对仗，非错别字

- 日期：2026-08-18
- 状态：已接受

## 背景

设备高峰期展示文案。DeepSeek 创始人真实姓名为「梁文**锋**」（金字旁）。用户明确要求展示文案使用「梁文**峰**」（山字旁）。

## 决策

所有**展示文案**统一使用：

- 高峰期 → 「**梁文峰**」（黄色）
- 非高峰期 → 「**梁文谷**」（绿色）

**这是刻意的文字选择，不是错别字**：与官方姓名「梁文锋」不同，但「峰」与「谷」同为山体地貌词，与产品展示的"峰谷时段"语义形成对仗（高峰=峰、空闲=谷），在设备屏幕上视觉上互为呼应。

## 涉及范围

- 设备屏幕文案（`sticks3/sticks3.ino`）
- 上位机状态回显（`host/src/liangzi_meter/ui.py`）
- 项目文档（README / CONTEXT.md）中的展示文案引用
- 代码注释同步使用「梁文峰」，并注明本 ADR

## 后果

- **正面**：峰/谷对仗语义自洽，符合产品主题。
- **负面（接受）**：与真实姓名"梁文锋"不同，外部读者可能误判为错别字——**本 ADR 即为此而写**，未来任何人看到"梁文峰"应视为设计意图，不应"好心"改回"梁文锋"。
- 协议字段、内部标识（如 `phase=peak/offpeak`）不涉及该文案，不受影响。

## 备选方案

- 使用真实姓名「梁文锋」：与官方一致，但失去峰/谷对仗效果，用户明确否决。
