# ADR-0004：提示音功能（alert tones）——RWR 告警音 + 高峰余额监控

- 日期：2026-08-21
- 状态：已接受

## 背景

liangzi-meter 是纯视觉摆件（峰谷颜色、余额红色告警）。用户希望引入声音反馈：进入高峰时段提示、高峰期余额减少时告警。音色沿用同工作区 rwr-alert 项目（War Thunder RWR 复刻）的「敌跟踪/敌导弹」告警音。

需求约束（与用户逐轮确认）：

- **总开关，默认关闭**，由上位机配置。
- 进入高峰播**敌跟踪音**一次。
- 高峰期间余额查询从 5 分钟加速到 **15 秒**。
- 检测到余额减少（比上次少 > 0.01 元）→ **持续播放敌导弹音**，无固定轮间间隔；直到某轮判定余额不再减少（≥ 上次）才停止。

## 决策

1. **配置**：协议新增 `alert_enabled`（bool，默认 false），固件 NVS 持久化，host 表单提供开关。**关闭 = 完全保持现状**（无音、查询恒 5 分钟）。
2. **播放器**：非阻塞 loop-tick 状态机（`alertTick()`），不建 FreeRTOS task。敌跟踪=一次性（播完自停），敌导弹=持续（循环至显式停止）。
3. **余额对比基准** = 上次成功查询值；触发条件 `current < prev − 0.01`；停止条件 `current ≥ prev`（含持平）或离开高峰或关开关。
4. **高峰边沿**：仅"非高峰→高峰"翻转播敌跟踪；上电首帧不触发。
5. **音量 96/255**（电池供电安全音量），音色沿用 RWR 原始频率（554.37/370/392Hz）。

## 涉及范围

- 固件：`sticks3/config.h`（配置字段）、`sticks3/alert.h`（新，播放器）、`sticks3/sticks3.ino`（协议 + 状态机）
- 上位机：`host/src/liangzi_meter/config.py`、`ui.py`
- 协议：`config` 消息新增 `alert_enabled`，`state` 回显

## 后果

- **正面**：桌面摆件获得"耳朵级"反馈；15s 高峰监控能最快感知扣费。
- **负面（接受）**：高峰期间 15s 一次余额查询增加 API 调用（一天高峰 7 小时 ≈ 1680 次，DeepSeek 余额接口可承受）；持续告警可能打扰——由"默认关闭 + 不再减少即停 + 离开高峰即停"三重约束兜底。
- 向后兼容：旧固件忽略未知字段，新固件缺失字段视为关闭。

## 备选方案

- **FreeRTOS task 播放**：rwr-alert 原做法，但 liangzi-meter 主循环密集（WiFi/TLS/串口/显示），task 与主循环并发调用 Speaker 需额外同步，收益低，否决。
- **每 30 秒间歇重播**：用户明确否决——要求"进入播放后连续，直到判定不再减少"。
- **非高峰也告警**：不在此范围，保持安静优先。
