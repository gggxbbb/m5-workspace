# CONTEXT.md — liangzi-meter 领域术语表

> 本文件只记录领域词汇与语义，不含实现细节。实现决策见 `docs/adr/`。

## 术语

### 设备与角色

- **设备（device）**：M5StickS3（K150），本项目的硬件载体。LCD 135×240，无独立 RTC，原生 USB CDC 串口。
- **固件（firmware）**：运行在设备上的 Arduino 程序（`sticks3/` 分支）。
- **上位机（host）**：运行在电脑上的 PyQt6 配置工具（`host/`），通过 USB 串口与设备通信。上位机是**配置的权威来源**，但设备在配置完成后可独立工作。

### 配置（config）

由上位机下发、固件持久化（NVS）的参数集合。语义上是一份**全量快照**，每次下发整体覆盖：

- **WiFi 凭据**：SSID + 密码。
- **NTP 服务器**：设备时间同步的时间源（默认 `ntp.aliyun.com`）。
- **API key**：DeepSeek 开放平台密钥，用于查询余额。配置动作发生在**上位机**，查询动作发生在**固件**。
- **峰谷时段覆盖（peak override）**：可选的高峰区间列表；下发后优先于固件内置的官方默认值。
- **屏幕方向（screen rotation）**：设备开机默认的显示方向（0=竖屏正常 / 1=顺时针90°(横屏) / 2=180° / 3=逆时针90°(横屏)），由上位机配置并持久化（见 ADR-0005）。
- **重力感应旋屏（gravity auto-rotate）**：可配置的总开关（`auto_rotate`，默认关）。关闭 = 固定 `screen_rotation` 方向；开启后设备随姿态自动旋转显示（经 BMI270 加速度判定 + 防抖，见 ADR-0005）。

未配置任何参数的状态称为**出厂态（factory state）**。

### 时间与峰谷

- **北京时间（Beijing time）**：设备唯一使用的时间域，UTC+8，来源于 NTP 同步。设备无独立 RTC，断电重启后依赖 NTP 重新同步。
- **高峰时段（peak window）**：官方定价中按北京时间划分的高峰区间。**周一至周五（不含中国法定节假日）9:00–12:00、14:00–18:00**，可被上位机覆盖时刻范围，但不能覆盖日期规则。
- **非高峰日（off-peak day）**：周六、周日及中国法定节假日全天按低谷价收取；调休形成的周末工作日仍属于周末，仍为低谷。时段切换倒计时跳过整天低谷日。固件内置 2026 年国务院公布的放假日期，后续年份须按年度通知更新。
- **高峰期（peak phase）**：当前时刻同时满足“高峰候选日”和任一高峰区间。展示文案「梁文峰」，**黄色**。注意用字为"山-峰"的峰，与「梁文谷」对仗，是刻意选择而非错别字（见 ADR-0003）。
- **非高峰期（off-peak phase）**：当前时刻不满足高峰条件（含整个周末及中国法定节假日）。展示文案「梁文谷」，**绿色**。
- **时段切换倒计时（phase countdown）**：距下一次峰谷切换的剩余时间。

### 供电与可见性

- **外接供电模式（external-power mode）**：设备接入 USB 电源的使用情境，屏幕持续可见。
- **电池省电模式（battery-saving mode）**：设备仅由电池供电的使用情境；屏幕按可配置的无人操作时间变暗或熄灭，并允许用户唤醒。
- **供电切换（power-source transition）**：插入 USB 会立即唤醒并应用外接供电亮度；拔出 USB 会应用电池正常亮度并从零开始无人操作计时。
- **省电配置（power-saving configuration）**：面向熟悉设备行为的用户开放亮度、超时、唤醒和待机策略参数，而非仅提供固定预设。
- **电池省电总开关（battery-saving master switch）**：决定电池供电时是否执行变暗、熄屏和后台浅睡策略；关闭时保持电池亮度常亮，但保留所有子项配置。
- **供电亮度配置（power-source brightness）**：外接供电亮度、电池正常亮度和电池低亮度分别可配置，供电来源或显示阶段变化时应用对应值。
- **变暗等待时间（dim timeout）**：进入电池低亮度前允许无人操作的时间，可设为永不变暗。
- **熄屏等待时间（screen-off timeout）**：进入熄屏监控前允许无人操作的时间，必须晚于有限的变暗等待时间，也可设为永不熄屏。
- **省电配置默认值（power-saving defaults）**：外接供电、电池正常和电池低亮度依次为 160、96、24，默认 30 秒变暗、2 分钟熄屏；旧配置缺少新字段时采用这些值。
- **省电预设（power-saving preset）**：常亮、均衡和省电三组可编辑的配置起点；选择预设只填充上位机表单，仍需主动下发，且不会限制后续逐项调整。
- **无人操作（inactivity）**：没有按键或明显拿起动作的持续状态；网络查询、时间刷新和其他后台任务不属于用户操作。
- **熄屏监控（screen-off monitoring）**：电池省电模式下屏幕熄灭后，设备仍持续执行峰谷判断、余额查询与提示音告警。
- **显示唤醒（display wake）**：用户按键或拿起设备后，屏幕恢复可见并重新开始计算无人操作时间。
- **拿起唤醒（lift-to-wake）**：设备检测到明显拿起动作后恢复屏幕可见；它独立于重力感应旋屏，即使固定屏幕方向也仍然有效。
- **拿起灵敏度（lift sensitivity）**：拿起唤醒由可配置的运动阈值、持续时间和防重复触发时间共同决定，使用产品级安全范围而非直接暴露 IMU 寄存器。
- **告警唤屏（alert display wake）**：检测到余额下降时，熄灭或变暗的屏幕恢复正常亮度，并像用户操作一样重新开始变暗与熄屏计时；进入高峰的提示音和普通后台事件不触发唤屏。
- **唤醒来源（wake source）**：设备按键与 USB 接入始终可以唤醒屏幕；拿起唤醒和余额下降告警唤屏可分别启用或关闭，峰谷切换不属于显示唤醒来源。
- **唤醒按键（wake press）**：屏幕熄灭时的首次 KEY1 或 KEY2 按键只恢复显示并被消费，不同时执行余额刷新或页面切换。
- **低亮度交互（dimmed interaction）**：屏幕处于低亮度时仍可正常操作；按键恢复电池正常亮度、重新开始无人操作计时，并同时执行原有功能。
- **续航优化目标（battery-life optimization goal）**：在保持熄屏监控与既定交互的前提下，相同使用场景的耗电应低于优化前；不承诺固定续航时长，结果以实测对比为准。
- **运行时省电（runtime power saving）**：无论外接供电还是电池供电，设备都可在保持屏幕策略、WiFi 关联、USB 串口响应和后台监控的前提下，让无线与处理器在任务间降低活动功耗。
- **分供电运行时策略（per-source runtime policy）**：外接供电与电池供电分别配置 WiFi 省电和处理器省电；外接供电保持 USB 串口随时响应，电池供电可采用更深入的浅睡。
- **联网待机（connected standby）**：保持 WiFi 关联和后台监控，同时允许无线进入 modem sleep；周期性断开 WiFi 仅作为实测收益不足后的后续方案。
- **外设按需供电（peripheral power on demand）**：IMU、扬声器与功放由启用中的产品功能自动管理，不提供可与功能配置冲突的裸硬件开关；麦克风因无录音职责而保持关闭。
- **省电诊断（power-saving diagnostics）**：设备上报实际供电来源、显示阶段、亮度、WiFi 与处理器省电状态、IMU 模式、电池电压及估算电量，供上位机确认配置是否生效。

### 余额

- **余额（balance）**：DeepSeek 账户当前总可用余额（`total_balance`，CNY），通过官方接口 `GET /user/balance` 查询，Bearer 鉴权。
- **余额告警阈值（balance warn threshold）**：可配置的金额下限（元，默认 10.00）。余额低于该值时，设备与上位机均以**红色**显示金额——红色是余额告警的专用语义色，峰谷状态不使用红色。
- **余额刷新（balance refresh）**：固件周期性（默认 5 分钟）或按 KEY1 手动触发的余额查询动作。查询失败时保留上次数值并标记为过期。

### 通信

- **串口协议（serial protocol）**：设备与上位机间经 USB CDC 串口（115200）传输的协议，**JSON Lines** 格式（每行一条 UTF-8 JSON，`\n` 分隔）。
- **握手（handshake）**：设备上电或收到 `ping` 后回复 `hello`（含型号/固件版本/是否已配置）的交互；上位机收到 `hello` 且本地有已保存配置时自动下发。
- **状态上报（state report）**：固件响应 `get_state` 或周期性上报的当前状态快照（时间/峰谷/余额/电量/WiFi 状态）。

### 提示音功能（alert tones）

- **提示音功能（alert tones）**：上位机可配置的总开关（`alert_enabled`，默认关）。**关闭 = 完全保持现状**（无任何声音、余额查询恒 5 分钟）；开启后启用高峰提示与余额监控告警（见 ADR-0004）。
- **敌跟踪音（lock tone）**：一次性提示音（高-低双音 ×2 组，约 0.9s）。仅在**进入高峰**（非高峰→高峰翻转）时播放一次。
- **敌导弹音（missile tone）**：持续告警音（急促高-低双音 ×3 音/组，组间短静音**连续循环**，不间歇）。高峰期检测到**余额减少**时进入播放，直到判定不再减少/离开高峰/关闭开关。
- **高峰监控（peak watch）**：开启提示音功能后，高峰期间余额查询频率由 5 分钟加速到 **15 秒**；非高峰恢复 5 分钟。
- **余额减少（balance decrease）**：当前余额比**上次成功查询值**低且差值 **> 0.01 元**，判定为余额减少（触发敌导弹音）；小于等于 0.01 元的波动视为舍入噪声，不触发。
- **余额对比基准（last balance）**：每次成功查询后更新的余额值，作为下一次"余额减少"判定的对比对象；无论开关与峰谷状态都持续维护。
- **不再减少（no decrease）**：当前余额 ≥ 上次成功查询值（含持平），持续敌导弹音停止的条件之一。

## 非目标（Non-goals）

- 不实现设备端配置热点（SoftAP 配网）；配置一律经上位机串口下发。
- 不实现 DeepSeek 对话/用量统计，只显示余额与峰谷状态。
- 设备不存储多个账户，同一时刻只维护一份配置。
- 本轮省电优化不实现会中断联网监控的深睡眠或 PMIC 关机；极限续航模式若需要，应作为独立能力设计。
- 本轮不实现内置电流测量或功耗测试模式，实际功耗由外部测量设备验证。
